## ⚡ Overview

The **Duxio Acquisition Engine** is a state-of-the-art client acquisition funnel designed exclusively for high-ticket coaching businesses. It replaces generic landing pages with a deep, connected ecosystem designed to attract, qualify, and convert premium prospects on autopilot.

Built with performance and conversion rate optimization (CRO) in mind, this engine utilizes behavioral psychology principles, advanced UI/UX glassmorphism, and a seamless data-capture flow to maximize booked calls.

## ✨ Key Features

- 🎨 **Premium Aesthetic**: Apple-inspired design system utilizing strict `oklch` color spaces, rich ambient gradient meshes, and dynamic Bento Box layouts.
- 💨 **Blazing Fast**: Powered by **Vite** and **React 18** for instant load times (crucial for ad traffic).
- 🧩 **TanStack Router**: Advanced client-side and server-side routing for seamless transitions.
- 📱 **Mobile-First Glassmorphism**: Responsive design with deep `backdrop-blur` layers that look stunning on iOS and Android devices.
- 🎯 **Frictionless Lead Capture**: Optimized 4-step audit form utilizing `react-hook-form` and `zod` validation to maximize conversion rates.

## 🛠️ The 7-Part System

This architecture natively integrates the **Duxio 7-Part Client Acquisition System**:

1. 🧲 **Attract**: Audience building mechanisms.
2. 👤 **Capture**: Irresistible lead magnets.
3. 🌪️ **Qualify**: Automated filtering.
4. 📅 **Book**: Direct calendar injection.
5. ⏱️ **Follow Up**: Automated show-up rate boosters.
6. 🤝 **Convert**: Pre-sold sales environments.
7. 🌱 **Nurture**: Long-term prospect cultivation.

## 🚀 Getting Started

### Prerequisites

- Node.js `v18+`
- npm `v9+`

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/Duxio-Acquisition-Engine.git

# Navigate into the directory
cd Duxio-Acquisition-Engine

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Building for Production

```bash
npm run build
npm run preview
```

### 🚀 Deploying to Vercel

This project is perfectly optimized for one-click deployment on **Vercel**.

1. Create a new project on [Vercel](https://vercel.com).
2. Connect your GitHub repository.
3. Vercel will automatically detect the **Vite** framework.
4. Leave the default build command (`npm run build`) and output directory (`dist`).
5. Click **Deploy**.

- **Design Tokens**: Pure whites, graphite inks, and a signature ambient blue (`var(--accent)`).
- **Icons**: Powered by `lucide-react`.
